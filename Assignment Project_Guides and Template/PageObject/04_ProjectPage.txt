# Positive Test examples are below write test process steps for each below test case

	Create Blank Project With Valid Name
		Navigate To New Project Page     BlankProjectUrl
		Input Project Name               ProjectName
		Select Visibility                ProjectVisibility
		Click Create Project Button
		Verify Page Should Contain       Project 'First project' was successfully created.

	Create Template Project
		Navigate To New Project Page     TemplateProjectUrl
		Select A Project Template        Pages/Plain HTML
		Click Use Template Button
		Input Project Name               TemplateProjectName
		Select Visibility                ProjectVisibility
		Click Create Project Button
		Verify Page Should Contain       Project 'Template project' was successfully created.

	Update Name Of Template Project
		Navigate To Project Settings     TemplateProjectName
		Clear Project Name Field
		Input Project Name               UpdatedProjectName
		Click Save Changes Button
		Verify Page Should Contain       Project was successfully updated.
		Verify Page Title Should Contain UpdatedProjectName

	Delete Template Project
		Navigate To Project Settings     UpdatedProjectName
		Scroll To Danger Zone Section
		Click Delete Project Button
		Input Project Name To Confirm    UpdatedProjectName
		Click Confirm Delete Button
		Verify Page Should Contain       Project 'First project updated' is in the process of being deleted.

	Validate Success Message After Project Creation
		Navigate To New Project Page     BlankProjectUrl
		Input Project Name               ProjectName
		Select Visibility                ProjectVisibility
		Click Create Project Button
		Verify Page Should Contain       Project 'First project' was successfully created.
		Verify Alert Banner Is Visible   success
